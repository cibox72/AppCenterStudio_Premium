0. Preparazione (10 minuti)

  1. Apri Firefox, Chrome e DuckDuckGo. In tutti e tre scrivi https://cibox72.github.io/AppCenterStudio_Premium/ e premi INVIO.
  2. Blocco Note con queste righe vuote: TOKEN GITHUB = / CODICE STUDIO = / LINK BENVENUTO = / LINK SELEZIONE CLIENTE = / LINK GALLERY CLIENTE = / CLIENTE 1 =
  3. Sul Desktop crea ORIGINALI con 10 foto AD ALTA risoluzione (nomi tipo IMG_6202.jpg).
  4. Da ORIGINALI crea le copie A BASSA risoluzione in una cartella Matrimonio e una Battesimo.

REGOLA D'ORO DELLE FOTO (per GRU): esporta a BASSA risoluzione (Lightroom: Esporta → JPEG → qualita' 20 → sRGB → lato lungo 1600–2000 px) e carica SOLO quelle. NON rinominare MAI ne' file ne' cartelle: nomi ed estensioni IDENTICI agli originali, altrimenti GRU non trova gli alta risoluzione.

1. ADMIN su Firefox: token GitHub

  1. github.com → "Sign up" → email, password, username → verifica via email.
  2. Immagine profilo → "Settings" → in fondo "Developer settings" → "Personal access tokens" → "Tokens (classic)".
  3. "Generate new token (classic)" → "Note" = AppCenterStudio → "Expiration" = No expiration → spunta "repo" → "Generate token".
  4. Copia SUBITO la stringa ghp_... nel Blocco Note: non la rivedrai piu'.

2. ADMIN su Firefox: studio e licenze (senza Netlify)

  1. Apri https://cibox72.github.io/AppCenterStudio_Premium/admin-offerte.html.
  2. Incolla il token → "Salva token" → "Aggiorna elenco".
  3. Card "Crea nuovo studio": codice (es. st-001), nome (es. G&L Studio), mesi di prova → "Crea studio". Lo vedi SUBITO in tabella: non serve uscire e rientrare.
  4. Sulla riga dello studio: "Estendi" (aggiunge mesi), "Sospendi/Attiva", "Rimuovi".
  5. Scrivi nel Blocco Note CODICE STUDIO = e LINK BENVENUTO = .../benvenuto.html?studio=IL-CODICE → mandalo allo studio su WhatsApp.

Gli errori "offers.json does not match..." non esistono piu': questa pagina riscrive i file correttamente.

3. ADMIN su Firefox: temi stagionali

  1. Apri admin-tema.html (stesso token) → clicca un periodo: Classico / Wedding / Natale / Carnevale / Pasqua / Estate / Inverno.
  2. Attendi ~1 minuto: TUTTE le app di TUTTI gli studi cambiano grafica.
  3. In alternativa, dal pannello admin del benvenuto (benvenuto.html?studio=...&admin=1) trovi la riga "CAMBIA STILE APP" con gli stessi 7 pulsanti.

4. STUDIO su Chrome: benvenuto e identita'

  1. Apri il LINK BENVENUTO ricevuto: badge "Licenza attiva", codice e scadenza nel formato gg/mm/aa.
  2. Sezione 1: Referente, WhatsApp (solo cifre con prefisso), Email, Citta', Note → "Invia i dati al fornitore". (Nel test NON inviare.)
  3. Sezione 2 "Identita' dello studio": Nome, P.IVA, Indirizzo, Telefono = UN SOLO numero WhatsApp (se ne scrivi di piu' vale il primo), Email, Note + logo → "Salva e invia al fornitore". Sezione sempre modificabile.
  4. Sezione 3: le tue app. Clicca "03 Clienti & Foto".

5. STUDIO su Chrome: clienti e foto (app 03)

  1. "Nuovo cliente": Mario Rossi → "Aggiungi cliente" → codice rossi-mario-001. Scrivilo nel Blocco Note.
  2. "Carica foto nel magazzino": scegli cliente → "Cartella foto" → entra in Matrimonio, seleziona tutte le foto (prima, MAIUSC, ultima) → "Apri" → "Carica nel magazzino" → aspetta "Completato: N foto caricate".
  3. Ripeti con Battesimo.
  4. "Archivio clienti": ora vedi le chip "10 foto nel magazzino" E "Cartelle: Matrimonio (5), Battesimo (5)".
  5. "Link gallery cliente" (dopo le ritoccate, passo 6): copia il link da mandare al cliente.

Le foto sono salvate temporaneamente e cancellate automaticamente dopo un determinato periodo: nei testi al cliente non nominare mai le piattaforme.

6. STUDIO su Chrome: selezione (app 04)

  1. Apri selezione-album/?studio=IL-CODICE (o da 03 "Apri Selezione per Album").
  2. Selezione in studio (caso normale): fai la scelta al PC come sempre → premi "Selezione in studio".
  3. Link da casa (solo chi non puo' venire): crea il link valido 7 giorni, copiato automaticamente → Blocco Note dopo LINK SELEZIONE CLIENTE = → mandalo al cliente. Le foto NON scelte si eliminano da sole all'invio.
  4. X selezione / X link casa: annulla una registrazione fatta per sbaglio.
  5. Carica ritoccate: seleziona le foto finali → carica. Poi in 03 premi "Link gallery cliente" → Blocco Note dopo LINK GALLERY CLIENTE =.
  6. "Gallery +6 mesi": prolunga la scadenza. "Text Gru": txt con i NOMI ESATTI per GRU. "PDF stampa": elenco per il laboratorio.

7. CLIENTE su DuckDuckGo: selezione e gallery

Selezione da casa

  1. Apre il link: intestazione studio, logo, messaggio, "Link valido fino al gg/mm/aa".
  2. Tocca una foto: si apre GRANDE; frecce/swipe/tastiera; cuore BIANCO = non scelta, ROSSO = scelta; contatore in alto.
  3. Sceglie 4-5 foto → "Invia selezione" → allo studio arriva il WhatsApp e le non scelte spariscono. (Nel test NON inviare.)

Gallery

  1. Apre il link gallery: pagina pulita con logo e "Disponibile fino al gg/mm/aa".
  2. Sfoglia e ingrandisce le foto finali. Scaduta la data vede "contatta lo studio" (tu puoi prorogare).

Se DuckDuckGo non carica le foto: icona SCUDO → disattiva protezione → ricarica.

8. STUDIO su Chrome: preventivi (app 01)

  1. Apri preventivi-contratti/?studio=IL-CODICE → compila anagrafiche, DATA e TIPO in evidenza, chiesa/location, spunta i servizi dal listino, sconto/buono.
  2. "Acconti ricevuti" → "+ Aggiungi acconto" → accanto "Ricevuta": scarica il PDF della ricevuta.
  3. "Salva in archivio" → numero P-2026-XXX → "Crea PDF da inviare": il PDF SI SCARICA con intestazione e riquadri firma.
  4. Quando il cliente firma: spunta "ACCETTATO E FIRMATO DAL CLIENTE" → "Trasforma in Contratto": da ora compare DA SOLO nell'agenda.
  5. Tab "Listini & Studio" (sezione UNICA): dati studio per i PDF + modifica listini.

9. STUDIO su Chrome: ricevute a blocchetto (app 08)

  1. Apri ricevute/?studio=IL-CODICE → cliente, servizio, "Ricevo €", data, "A titolo di...", note → "Salva ricevuta".
  2. "Visualizza": layout a BLOCCHETTO (numero grande, data, importo, firme, "Soggetta a bollo vigente").
  3. "PDF": formato stretto tipo scontrino, pronto da stampare e firmare.

10. STUDIO su Chrome: workflow (app 02)

  1. Apri workflow/?studio=IL-CODICE → "+ Nuovo Servizio" → cliente, tipo, data → "Salva".
  2. Clicca il servizio: vedi le sezioni FOTO e VIDEO con tutti gli step.
  3. FOTO: spunta "Archiviazione" → compila Fatto da (Studio/Collaboratore), NAS e i 3 HD → data automatica. Poi RAW→JPEG, Selezione (studio/link + copertina art+azienda), Grafica, Invio laboratorio (azienda), Consegna laboratorio, Album, File non elaborati.
  4. VIDEO: Archiviazione, Musiche SÌ/NO con 4 campi link, Inviato montaggio (nome collaboratore), Video montato ricevuto (persona/link), Consegna con pulsanti USB 1-5 oppure link.
  5. "Visualizza" riepilogo completo; "PDF" scarica il foglio di lavorazione; "Tabella Clienti" stato lavori con percentuali.
  6. Configura le TUE sezioni: apri workflow/?studio=IL-CODICE&admin=1 → banner "Configura sezioni" → rinomina/colora/elimina sezioni e step, cambia tipo step, "+ Aggiungi step", "+ Aggiungi nuova sezione" → "Salva configurazione": vale per tutti i servizi.

11. STUDIO su Chrome: agenda (app 07)

  1. Apri agenda/?studio=IL-CODICE: calendario sfogliabile; i CONTRATTI compaiono DA SOLI nel giorno del servizio; preventivi futuri in verde chiaro.
  2. Clicca un giorno → "+ Nuovo appuntamento" (data, ora, titolo, tipo, note) → "Aggiungi al giorno". Se c'e' un contratto vedi "Data impegnata" ma puoi aggiungere un secondo evento.
  3. "Promemoria WhatsApp": copia gli impegni di OGGI e apre WhatsApp al numero dello studio (se il testo non entra da solo: Cmd+V).
  4. Ogni mattina, aprendo l'app, i due PC mostrano il promemoria (notifica desktop se consentita).

12. STUDIO su Chrome: email (app 09)

  1. Apri email/?studio=IL-CODICE → card "Mittente": email studio + PEC facoltativa → "Salva mittente".
  2. "Modello rapido" (appuntamento, pronto, saldo, grazie, ricevuta) o testo libero → destinatario e oggetto.
  3. "Invia con app email" / "Invia con PEC" (si apre il tuo programma di posta) oppure "Copia oggetto + testo" per la webmail. "Salva in archivio" tiene la copia.

13. Due PC dello stesso studio: sync cloud automatica

CosaDove vaA cosa serve

L'avviso mattutino compare su entrambi i PC perche' entrambi leggono gli stessi impegni dal cloud.

14. ADMIN: offerte e fine prova

  1. admin-offerte.html → "Crea offerta": studio, prezzo, mesi, descrizione → "Crea offerta" → "Copia link" → manda allo studio.
  2. Studio: apre il link benvenuto → riquadro nero con l'offerta → "Paga ora con PayPal" → ti manda la ricevuta.
  3. Tu: verifica su PayPal → "Estendi" sulla riga dello studio: la scadenza si allunga.

15. Salvare le configurazioni sul tuo PC (cartella ACS-BACKUP)

  • Worker Cloudflare: dash.cloudflare.com → Workers & Pages → acs-api → "Edit code" → copia tutto → salva come acs-api.js (rifallo dopo ogni aggiornamento).
  • GitHub: scarica lo zip del repo quando vuoi.
  • Netlify (solo modulo identita'): dashboard → Deploys → ultimo deploy → "Download deploy".
  • R2: dashboard → R2 → acs-foto → scarica i file che vuoi (backup foto clienti).
