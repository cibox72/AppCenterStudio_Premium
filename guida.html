1. ADMIN su Firefox: token GitHub

  1. github.com → "Sign up" → email, password, username → verifica via email.
  2. Immagine profilo → "Settings" → in fondo "Developer settings" → "Personal access tokens" → "Tokens (classic)".
  3. "Generate new token (classic)" → "Note" = AppCenterStudio → "Expiration" = No expiration → spunta "repo" → "Generate token".
  4. Copia SUBITO la stringa ghp_... nel Blocco Note: non la rivedrai piu'.

2. ADMIN su Firefox: portale, studio, credenziali, temi

  1. Apri il portale → "Utente" = admin, "Password" = 58879@Stella → "Entra".
  2. Card "Token GitHub": incolla il token → "Salva token".
  3. Card "Studi & Licenze": nome studio (es. G&L Studio), giorni di prova → "Crea studio". Nascono in automatico utente (= nome studio) e password: li vedi nel riquadro grigio della riga dello studio.
  4. "Copia credenziali": copia utente + password + link benvenuto → incollali nel Blocco Note e mandali allo studio su WhatsApp.
  5. "Link benvenuto": copia solo il link (gia' incluso nelle credenziali).

  7. "Nuova password": rigenera la password (la vecchia smette di funzionare).
  8. Card "Cambia stile app (tutti gli studi)": 7 pulsanti SOLO TESTO (CLASSICO, WEDDING, NATALE, CARNEVALE, PASQUA, ESTATE, INVERNO) con fascia colore. Clicca un tema → conferma → dopo ~1 minuto TUTTE le app di TUTTI gli studi cambiano grafica. Il pulsante attivo ha bordo nero.

I pulsanti tema sono eleganti (scritta serif maiuscola + fascia colore): niente emoji e niente immagini.

12. Dati al sicuro: salvataggio automatico globale

Non devi premere niente. Ogni volta che apri una qualsiasi app, il sistema fa da solo backup (se quel PC ha i dati) e ripristino (se quel PC e' vuoto): identita', logo, listini, mittente email + tutti i dati di lavoro (preventivi, contratti, workflow, agenda, ricevute, clienti, email) e le foto nel magazzino.

  1. REGOLA UNICA: su OGNI PC dello studio metti il link benvenuto nei Preferiti (Ctrl+D / Cmd+D). I preferiti non si cancellano con la cronologia.
  2. Se cancelli la cronologia o cambi PC: riapri il Preferito del benvenuto → login con utente+password → tutto torna operativo in pochi secondi.
  3. La prima volta su un PC nuovo: ricarica forte con Ctrl+F5 (Mac: Cmd+Shift+R).
  4. Cassaforte extra (facoltativa): "Backup globale" in una qualsiasi app scarica un file .json tuo personale.
SituazioneCosa succede
Cronologia cancellataRiapri il Preferito → login → tutto torna da solo
PC nuovo / rete diversa (casa, hotspot)Apri il link benvenuto → login → tutto torna da solo (la rete non conta)
Due PC alternatiOgni apertura allinea i due PC automaticamente
Studio "spento" dall'adminLo studio vede "Accesso spento dal fornitore" finche' non lo riaccendi

13. ADMIN: offerte e fine prova

  1. Portale admin → card "Offerte agli studi": studio, prezzo, mesi, descrizione → "Crea offerta" → "Copia link" → manda allo studio.
  2. Studio: apre il link benvenuto (login) → riquadro nero con l'offerta → "Paga ora con PayPal" → ti manda la ricevuta.
  3. Tu: verifica su PayPal → "Estendi licenza": la scadenza si allunga.

14. Salvare le configurazioni sul tuo PC (cartella ACS-BACKUP)

  • Worker Cloudflare: dash.cloudflare.com → Workers & Pages → acs-api → "Edit code" → copia tutto → salva come acs-api.js (rifallo dopo ogni aggiornamento).
  • GitHub: scarica lo zip del repo quando vuoi.
  • R2: dashboard → R2 → acs-foto → scarica i file che vuoi (backup foto clienti).
