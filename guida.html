0. Preparazione (10 minuti)

  1. Apri Firefox, Chrome e DuckDuckGo. In tutti e tre scrivi https://cibox72.github.io/AppCenterStudio_Premium/ e premi INVIO.
  2. Blocco Note con queste righe vuote: TOKEN GITHUB = / CODICE STUDIO = / LINK BENVENUTO = / LINK SELEZIONE CLIENTE = / LINK GALLERY CLIENTE = / CLIENTE 1 =
  3. Sul Desktop crea ORIGINALI con 10 foto AD ALTA risoluzione (nomi tipo IMG_6202.jpg).
  4. Da ORIGINALI crea le copie A BASSA risoluzione in una cartella Matrimonio e una Battesimo.

REGOLA D'ORO DELLE FOTO (per GRU): esporta a BASSA risoluzione (Lightroom: Esporta → JPEG → qualita' 20 → sRGB → lato lungo 1600–2000 px) e carica SOLO quelle. NON rinominare MAI ne' file ne' cartelle: nomi ed estensioni IDENTICI agli originali, altrimenti GRU non trova gli alta risoluzione.

1. ADMIN su Firefox: token GitHub

  1. github.com → "Sign up" → email, password, username → verifica via email.
  2. Immagine profilo → "Settings" → in fondo "Developer settings" → "Personal access tokens" → "Tokens (classic)".
  3. "Generate new token (classic)" → "Note" = AppCenterStudio → "Expiration" = No expiration → spunta "repo" → "Generate token".
  4. Copia SUBITO la stringa ghp_... nel Blocco Note: non la rivedrai piu'.

2. ADMIN su Firefox: portale, studio e temi

  1. Apri https://cibox72.github.io/AppCenterStudio_Premium/ → "Utente" = admin, "Password" = 58879@Stella → "Entra".
  2. Card "Token GitHub": incolla il token → "Salva token".
  3. Card "Studi & Licenze": nome studio (es. G&L Studio), giorni di prova → "Crea studio" → nasce st-001. Scrivilo nel Blocco Note.
  4. "Link benvenuto": copia il link → Blocco Note dopo LINK BENVENUTO = → mandalo allo studio su WhatsApp.
  5. Card "Cambia stile app (tutti gli studi)": 7 pulsanti SOLO TESTO (CLASSICO, WEDDING, NATALE, CARNEVALE, PASQUA, ESTATE, INVERNO) con fascia colore. Clicca un tema → conferma → dopo ~1 minuto TUTTE le app di TUTTI gli studi cambiano grafica. Il pulsante attivo ha bordo nero.

I pulsanti tema sono eleganti (scritta serif maiuscola + fascia colore): niente emoji e niente immagini.

4. STUDIO su Chrome: clienti e foto (app 03)

  2. "Carica foto nel magazzino": scegli cliente → "Cartella foto" → entra in Matrimonio, seleziona tutte le foto → "Apri" → "Carica nel magazzino" → "Completato: N foto caricate nella cartella Matrimonio".

5. STUDIO su Chrome: selezione (app 04)

  2. "Carica foto" (se non fatto in 03). "Selezione in studio": fai la scelta al PC → registra.

  5. "Gallery +6 mesi" prolunga; "X selezione" / "X link casa" annullano errori; "Text Gru" scarica i nomi esatti; "PDF stampa" l'elenco per il laboratorio.

6. CLIENTE su DuckDuckGo: selezione e gallery

Selezione da casa

  1. Apre il link: intestazione studio, logo, messaggio, "Link valido fino al gg/mm/aa".
  2. Tocca una foto: GRANDE; frecce/swipe/tastiera; cuore BIANCO = non scelta, ROSSO = scelta; contatore in alto.
  3. Sceglie 4-5 foto → "Invia selezione": allo studio arriva il WhatsApp e le non scelte spariscono. (Nel test NON inviare.)

Gallery

  1. Apre il link gallery: pagina pulita con logo e "Disponibile fino al gg/mm/aa".
  2. Pulsanti per cartella ("Tutte" / "Matrimonio" / "Battesimo") per cambiare gruppo; tocca una foto per ingrandirla.

Se DuckDuckGo non carica le foto: icona SCUDO → disattiva protezione → ricarica.

7. STUDIO su Chrome: preventivi (app 01)

  1. Apri preventivi-contratti/?studio=IL-CODICE → compila anagrafiche, DATA e TIPO in evidenza, chiesa/location, spunta i servizi, sconto/buono.
  2. "Acconti ricevuti" → "+ Aggiungi acconto" (data, importo, nota). Accanto a ogni acconto il pulsante "Ricevuta": scarica la ricevuta in stile blocchetto 80mm con TUTTI gli acconti versati e il saldo residuo.
  3. "Piano di pagamento" → "+ Aggiungi voce" (data, importo, descrizione) → pulsante verde "PDF piano di pagamento": stampa SOLO il piano, cosi' il cliente sa come pagare.
  4. "Salva in archivio" → numero P-2026-XXX → "Crea PDF da inviare".
  5. Quando il cliente firma: spunta "ACCETTATO E FIRMATO" → "Trasforma in Contratto": nell'archivio vedi subito il badge rosso CONTRATTO e compare in agenda.
  6. Tab "Listini & Studio": pulsante "Salva dati studio" (i dati finiscono sui PDF) + modifica listini.

8. STUDIO su Chrome: ricevute (app 08)

  1. Apri ricevute/?studio=IL-CODICE → cliente, servizio, "Ricevo €", data, "A titolo di", note → "Salva ricevuta".
  2. "Visualizza": layout a BLOCCHETTO (numero grande, data, importo, firme, "Soggetta a bollo vigente").
  3. "PDF": formato stretto 80mm pronto da stampare e firmare.

9. STUDIO su Chrome: workflow (app 02)

  1. Apri workflow/?studio=IL-CODICE → "+ Nuovo Servizio" → cliente, tipo, data → "Salva".
  2. Clicca il servizio: sezioni FOTO (8 step) e VIDEO (5 step).
  3. FOTO: spunta "Archiviazione" → compila Fatto da (Studio/Collaboratore), NAS, HD1-3 → data automatica. Poi RAW→JPEG, Selezione (studio/link + copertina art+azienda), Grafica, Invio laboratorio, Consegna laboratorio, Album, File non elaborati.
  4. VIDEO: Archiviazione; Musiche SÌ/NO con 4 campi link; Inviato montaggio (collaboratore); Video montato ricevuto (persona/link); Consegna con pulsanti USB 1-5 oppure link.
  5. I radio (studio/link, SÌ/NO, persona/link, USB/link) sono vuoti finche' non li scegli tu: niente pallini blu attivati per sbaglio.
  6. "Visualizza" riepilogo; "PDF" foglio di lavorazione; "Tabella Clienti" stato lavori.
  7. Configura le TUE sezioni: apri workflow/?studio=IL-CODICE&admin=1 → "Configura sezioni" → rinomina/colora/elimina sezioni e step, cambia tipo, "+ Aggiungi step", "+ Aggiungi nuova sezione" → "Salva configurazione". Vale per tutti i servizi.

10. STUDIO su Chrome: agenda (app 07)

  1. Apri agenda/?studio=IL-CODICE: calendario sfogliabile; i CONTRATTI compaiono DA SOLI nel giorno del servizio; preventivi futuri in verde chiaro.
  2. Clicca un giorno → "+ Nuovo appuntamento" → "Aggiungi al giorno". Se c'e' un contratto vedi "Data impegnata" ma puoi aggiungere un secondo evento.
  3. "Promemoria WhatsApp": copia gli impegni di OGGI e apre WhatsApp al numero dello studio (se il testo non entra da solo: Cmd+V).

11. STUDIO su Chrome: email (app 09)

  1. Apri email/?studio=IL-CODICE → "Mittente": email studio + PEC facoltativa → "Salva mittente".
  2. "Modello rapido" o testo libero → destinatario e oggetto → "Invia con app email" / "Invia con PEC" / "Copia oggetto + testo".

12. Due PC dello stesso studio: sync cloud automatica

13. ADMIN: offerte e fine prova

  1. Portale admin → card "Offerte agli studi" (o admin-offerte.html): studio, prezzo, mesi, descrizione → "Crea offerta" → "Copia link" → manda allo studio.
  2. Studio: apre il link benvenuto → riquadro nero con l'offerta → "Paga ora con PayPal" → ti manda la ricevuta.
  3. Tu: verifica su PayPal → "Estendi licenza": la scadenza si allunga.

14. Salvare le configurazioni sul tuo PC (cartella ACS-BACKUP)

  • Worker Cloudflare: dash.cloudflare.com → Workers & Pages → acs-api → "Edit code" → copia tutto → salva come acs-api.js (rifallo dopo ogni aggiornamento).
  • GitHub: scarica lo zip del repo quando vuoi.
  • R2: dashboard → R2 → acs-foto → scarica i file che vuoi (backup foto clienti).
