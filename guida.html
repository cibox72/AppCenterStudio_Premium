0. Preparazione (10 minuti)

  1. Apri Firefox, Chrome e DuckDuckGo. In tutti scrivi https://cibox72.github.io/AppCenterStudio_Premium/ e INVIO.
  2. Blocco Note: TOKEN GITHUB = / CODICE STUDIO = / UTENTE STUDIO = / PASSWORD STUDIO = / LINK BENVENUTO = / LINK SELEZIONE = / LINK GALLERY = / CLIENTE 1 =
  3. Desktop: cartella ORIGINALI con 10 foto ALTA; da queste crea le copie BASSA in Matrimonio e Battesimo.

REGOLA D'ORO FOTO (GRU): Lightroom Esporta → JPEG → qualita' 20 → sRGB → lato lungo 1600-2000 px. NON rinominare mai file o cartelle.

1. ADMIN su Firefox: token GitHub

  1. github.com → "Sign up" → verifica email.
  2. Settings → Developer settings → Personal access tokens → Tokens (classic) → "Generate new token (classic)".
  3. "Note" = AppCenterStudio; "Expiration" = No expiration; spunta "repo" → "Generate token". Copia ghp_... nel Blocco Note.

2. ADMIN: studio, credenziali, WhatsApp, offerte

  1. Portale → admin / 58879@Stella → "Entra". Card "Token GitHub" → "Salva token".
  2. Card "Studi & Licenze": nome studio, WhatsApp studio (obbligatorio), giorni → "Crea studio". Nascono utente (= nome studio) e password (riquadro grigio).
  3. "Invia su WhatsApp": apre WhatsApp al numero dello studio con link benvenuto + utente + password gia' scritti. In alternativa "Copia credenziali".
  4. "Accendi/Spegni": blocca/sblocca l'accesso. "Nuova password": rigenera.
  5. Card "Cambia stile app": 7 pulsanti SOLO TESTO (niente emoji/immagini); dopo ~1 minuto tutte le app cambiano.
  6. Card "Offerte agli studi": "Crea offerta"; su ogni offerta "Modifica" (prezzo, mesi, descrizione), "Copia link", "Estendi licenza", "Rimuovi".

3. STUDIO su Chrome: login e benvenuto

  1. Apri il LINK BENVENUTO. Pagina "Accesso studio": utente + password → "Entra". Il pulsante "Mostra" accanto alla password la rende visibile per controllare.
  2. Se lo studio e' nuovo i campi delle sezioni 1 e 2 sono VUOTI (niente dati di altri studi o test precedenti).
  3. Sezione 1: dati contatto → "Invia i dati al fornitore". Sezione 2: identita' studio con UN SOLO numero WhatsApp + logo → "Salva e invia al fornitore".
  4. Sezione 3: le app.

4. STUDIO: clienti e foto (app 03)

  1. "Nuovo cliente" → Mario Rossi → "+ Aggiungi cliente".
  2. "Carica foto nel magazzino": cartella Matrimonio → carica; ripeti con Battesimo.
  3. "Archivio clienti": foto suddivise per cartella. Pulsanti: "🗑 Elimina cartella", "✕" su una foto, "Svuota magazzino".
  4. Chiudi il browser e riapri: l'archivio clienti torna da solo (ripristino dal cloud all'avvio).
  5. "Apri selezione Album" (pulsante grande) e "Link gallery cliente".

5. STUDIO: selezione (app 04)

  1. "Selezione in studio" oppure "Link da casa" (7 giorni).
  2. Dopo "Link da casa" premi il verde "Invia su WhatsApp": WhatsApp si apre con messaggio e link gia' pronti (niente copia-incolla).
  3. "Carica ritoccate" → poi in 03 "Link gallery cliente". "Gallery +6 mesi", "X selezione", "X link casa", "Text Gru", "PDF stampa".

6. CLIENTE su DuckDuckGo

  • Selezione: cuore BIANCO/ROSSO, foto GRANDE, frecce/swipe, "Invia selezione".
  • Gallery: selettori "Tutte" / "Matrimonio" / "Battesimo"; scadenza visibile.
  • Se le foto non caricano: SCUDO → disattiva protezione → ricarica.

7. STUDIO: preventivi (app 01)

  1. Compila cliente, DATA e TIPO in evidenza, luoghi, servizi, sconto.
  2. "Acconti ricevuti": "+ Aggiungi acconto" → accanto "Ricevuta" = PDF stile blocchetto 80mm con tutti gli acconti, il saldo residuo E il quadratino di accettazione (pieno se spuntato, vuoto da firmare se no).
  3. "Piano di pagamento": le 4 voci di default sono gia' pronte SENZA date (Caparra / Prima dell'evento / Alla selezione delle foto / Prima della stampa): metti solo gli importi. "+ Aggiungi voce" e pulsante verde "PDF piano di pagamento" (senza date, con firme).
  4. Card "Accettazione": casella grande con bordo nero "ACCETTATO E FIRMATO DAL CLIENTE". Nel PDF preventivo il quadratino e' ACCANTO alla scritta "ACCETTAZIONE DEL PREVENTIVO".
  5. "Salva in archivio": messaggio chiaro in italiano se manca il nome cliente; altrimenti salva con numero P-2026-XXX.
  6. "Trasforma in Contratto": spunta da solo la casella, mette il badge rosso CONTRATTO e la data in agenda.
  7. Tab "Preventivi & Contratti": ogni riga con Apri/Modifica, PDF/Stampa (stampa diretta), Elimina + pulsante "PDF elenco archivio".
  8. Tab "Archivio Clienti": SOLO nome cliente, codice (P-2026-XXX), tipo (Preventivo/CONTRATTO) in ordine alfabetico, con Apri/Modifica, PDF/Stampa e Elimina (per cancellare prove o documenti). NIENTE totali o fatturato.
  9. Tab "Listini & Studio": "Salva dati studio" (finiscono sui PDF) + listini modificabili.

8. STUDIO: ricevute (app 08)

  1. Cliente, servizio, importo, data, "A titolo di" → "Salva ricevuta".
  2. "Visualizza" = blocchetto; "PDF" = formato 80mm con firme e bollo.

9. STUDIO: workflow (app 02)

  1. "+ Nuovo Servizio" → clicca il servizio: sezioni FOTO (8 step) e VIDEO (5 step).
  2. I radio (studio/link, SI/NO, persona/link, USB/link) sono VUOTI finche' non li scegli: niente pallini attivati per sbaglio; in "Visualizza" vedi solo cio' che hai davvero completato.
  3. Admin sezioni: workflow/?studio=CODICE&admin=1 → "Configura sezioni".

10. STUDIO: agenda (07) ed email (09)

  • Agenda: contratti automatici nel giorno del servizio; "+ Nuovo appuntamento"; "Promemoria WhatsApp"; avviso "Data impegnata".
  • Email: "Salva mittente", modelli rapidi, invio con app email/PEC o copia.

11. Dati al sicuro + cambiare PC

Ogni salvataggio va nel cloud ("Sync cloud: ✓"). REGOLA UNICA: link benvenuto nei Preferiti su ogni PC.

Prima di uscire da un PC

  1. Controlla "Sync cloud: ✓" nelle app usate.
  2. (Consigliato) "Backup globale" → scarica il .json → mandatelo su WhatsApp/email.

Sull'altro PC (casa, notebook...)

  1. Apri il Preferito del link benvenuto (?studio=...) → login con utente+password ("Mostra" per controllare).
  2. Apri le app: i dati arrivano da soli ("Sync: X aggiunti"). Anche le cartelle foto (sono nel magazzino cloud).
  3. Se una pagina sembra vecchia: Ctrl+F5.
  4. Se manca qualcosa: "Ripristino globale" con il file .json che ti sei mandato.

Il token GitHub del portale admin NON viaggia col cloud: se apri l'admin su un altro PC, reincolla il token ghp_... dal Blocco Note.

12. ADMIN: offerte e fine prova

  1. "Crea offerta" → "Copia link" → studio paga con PayPal → tu "Estendi licenza". Con "Modifica" correggi prezzo/mesi/descrizione.
