Clienti & Foto — Gestione codici e cartelle Netlify

🌐 1. Preparazione Netlify (fai una volta sola)

Per far funzionare tutte le app serve un sito Netlify permanente.
1. Clicca sotto per creare l'account gratis (se non l'hai già fatto).
2. Poi trascina una cartella vuota sul Netlify Drop per creare il sito (gli servirà un nome tipo studio-tuo.netlify.app).
3. Copia il link del sito creato e incollalo qui sotto → Salva.
🌐 Apri Netlify Drop

✅ Memorizzato

➕ 2. Aggiungi Nuovo Cliente

Inserisci nome e cognome → il sistema genera un codice univoco (es. rossi-001) che userai in tutte le app.

👥 3. Elenco Clienti

Per caricare le foto di un cliente: clicca 📤 Carica foto → trascina la cartella sul Netlify Drop → il sito le metterà in sito-tuo.netlify.app/codice-cliente/.
